LEDGER EXPLAINER

Why parse starts at row 2: the template header occupies row 1, and the first item record normally begins in Excel row 3. We intentionally anchor parsing at row index 2 so category titles and header notes are skipped while the item-level ledger stays stable.

Order formula: ORDER NEEDED = MAX(0, (PAR + SALES PROJECTION) - CURRENT INV). This keeps the order recommendation from going negative when the current stock is already above the target threshold.

Sales and reconciliation: when no new shipments are received, the delta between previous inventory and current inventory reflects actual movement. A negative variance can signal unlogged giveaways, theft, or product waste, while elevated stock with weak demand can indicate over-ordering risk.
